# The Drell Legacy Foundation Website

This is a free, responsive static website that can be hosted at no cost.

## Files
- `index.html`
- `styles.css`
- `script.js`
- `assets/back-to-school-drive-2026.png`

## Free hosting options

### GitHub Pages
1. Create a free GitHub account.
2. Create a new public repository.
3. Upload all files and folders from this package.
4. Open **Settings → Pages**.
5. Choose the main branch and root folder.
6. GitHub will provide a free public website address.

### Netlify
1. Create a free Netlify account.
2. Drag the entire website folder into Netlify's deployment area.
3. Netlify will publish the site and provide a free address.

## Before publishing
Confirm all event details, contact information, organization status, and donation language.
